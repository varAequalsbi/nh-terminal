### 2. Real Price Chart
```javascript
// Current (placeholder):
<div className="h-32 bg-bg-tertiary border border-dashed">
  [Chart Visualization]
</div>

// Replace with (real component):
<PriceChart data={priceData.history} />
```

### 3. Real Signal Charts
```javascript
// Current (placeholder):
<div className="h-8 bg-bg-tertiary">
  [Chart]
</div>

// Replace with (real component):
<ResponsiveContainer width="100%" height="100%">
  <LineChart data={chartData}>
    <Line type="monotone" dataKey="value" stroke="#gold" />
  </LineChart>
</ResponsiveContainer>
```

## 🎨 Styling Reference

All styling is done with Tailwind classes:

| Component | Class | Color |
|-----------|-------|-------|
| Card Border | `border-cyan-500` | Cyan |
| Card Background | `bg-bg-secondary` | Dark Navy |
| Text Primary | `text-text-primary` | White |
| HIGH Badge | `bg-color-danger` | Red |
| MEDIUM Badge | `bg-color-warning` | Yellow |
| LOW Badge | `bg-cyan-600` | Cyan |

| Bearish Chart | `stroke="#ef4444"` | Red |

No custom CSS needed - all Tailwind!
